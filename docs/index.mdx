# Calendar views that belong in your product

`@ricsam/react-mui-calendar` provides interactive month and week views without a scheduling backend, opinionated event editor, or framework runtime. Your application owns the event data and the components report interactions through callbacks.

## Install

```bash
npm install @ricsam/react-mui-calendar @mui/material @emotion/react @emotion/styled date-fns
```

## Design principles

- **Controlled data.** There is no hidden event store. Pass `events` and update them after callbacks.
- **Consumer-owned color.** Pass final CSS colors through `event.styling`; the calendar does not infer ownership or mutate old-event colors.
- **MUI-native.** Use the bundled calendar theme alone or merge it into your existing Material UI theme.
- **Focused scope.** Month, week, and their navigation are included. The former timeline component has been removed.

<Note>
  `start` and `end` are both required. For an all-day event, pass the start and
  end of the day. Events of 24 hours or longer are displayed in the all-day
  area.
</Note>
